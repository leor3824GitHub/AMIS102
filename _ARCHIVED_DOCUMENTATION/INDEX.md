## Why Archive?

Consolidation provides several benefits:

1. **Reduced Confusion** — One comprehensive guide per domain instead of many scattered files
2. **Better Organization** — Related content grouped logically
3. **Easier Navigation** — Table of contents in consolidated guides
4. **Historical Preservation** — Original files preserved if detailed reference needed
5. **Maintenance** — Single file to update instead of multiple related files
